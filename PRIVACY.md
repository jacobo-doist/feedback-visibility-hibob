# Privacy policy

Feedback Visibility Default for HiBob collects no data.

- It runs only on `app.hibob.com`.
- On that site, it reads and changes one form field: "Who will see this feedback?" in the Give feedback and Request feedback forms. It does not read your feedback, your colleagues' details or anything else on the page.
- It sends nothing to any server, including its author's. It makes no network requests at all.
- It stores nothing, in the browser or anywhere else.
- It uses no analytics, tracking or third-party code.

The full source code is in this repository, in [`extension/content.js`](extension/content.js).

Questions: open an issue at https://github.com/jacobo-doist/feedback-visibility-hibob/issues.
